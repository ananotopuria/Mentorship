# Module 1 — HTML & CSS Tech Interview

ეს ფაილი შეიცავს დამწყები დონის HTML და CSS ტექნიკური გასაუბრების კითხვებსა და მოკლე პასუხებს.

## HTML

### 1. რა არის HTML და რა დანიშნულება აქვს?

HTML (`HyperText Markup Language`) არის მარკირების ენა, რომლითაც ვქმნით ვებგვერდის სტრუქტურასა და შინაარსს: სათაურებს, ტექსტებს, სურათებს, ბმულებს, ფორმებს და სხვა ელემენტებს. HTML პროგრამირების ენა არ არის, რადგან ლოგიკასა და ალგორითმებს არ ასრულებს.

### 2. რა განსხვავებაა HTML ტეგსა და ატრიბუტს შორის?

ტეგი ქმნის HTML ელემენტს, ხოლო ატრიბუტი ელემენტს დამატებით ინფორმაციას ან თვისებას აძლევს.

```html
<a href="https://example.com">Visit website</a>
```

აქ `<a>` არის ტეგი, ხოლო `href` — ატრიბუტი.

### 3. რა განსხვავებაა `class` და `id` ატრიბუტებს შორის?

- `class` შეიძლება რამდენიმე ელემენტს ჰქონდეს და ძირითადად გამოიყენება საერთო სტილების მისაცემად.
- `id` გვერდზე უნიკალური უნდა იყოს და კონკრეტული ელემენტის იდენტიფიცირებისთვის გამოიყენება.

```html
<p class="text">First paragraph</p>
<p class="text" id="important-text">Second paragraph</p>
```

### 4. აღწერეთ HTML დოკუმენტის ძირითადი სტრუქტურა.

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <header>Header</header>
    <main>Main content</main>
    <footer>Footer</footer>
  </body>
</html>
```

`<head>` შეიცავს გვერდის შესახებ ინფორმაციას, ხოლო `<body>` — მომხმარებლისთვის ხილულ შინაარსს.

### 5. ტექსტის დასაფორმატებლად რომელი HTML ტეგები იცით?

მაგალითად: `<h1>`–`<h6>`, `<p>`, `<strong>`, `<em>`, `<b>`, `<i>`, `<mark>`, `<small>`, `<del>`, `<sub>`, `<sup>` და `<br>`.

### 6. რა განსხვავებაა `<strong>` და `<b>` ტეგებს შორის?

ორივე ტექსტს ნაგულისხმევად ამუქებს, მაგრამ `<strong>` აღნიშნავს, რომ ტექსტს მნიშვნელოვანი მნიშვნელობა აქვს. `<b>` მხოლოდ ვიზუალურად გამოყოფს ტექსტს დამატებითი სემანტიკური მნიშვნელობის გარეშე.

### 7. შესაძლებელია თუ არა inline ელემენტის block ელემენტად გადაქცევა და როგორ?

დიახ, CSS-ის `display` property-ის გამოყენებით:

```css
span {
  display: block;
}
```

### 8. რომელი CSS `position` მნიშვნელობები იცით?

ძირითადი მნიშვნელობებია:

- `static` — ნაგულისხმევი პოზიციონირება;
- `relative` — ელემენტი გადაადგილდება თავისი საწყისი ადგილიდან;
- `absolute` — პოზიციონირდება უახლოესი პოზიციონირებული მშობლის მიმართ;
- `fixed` — ფიქსირდება viewport-ის მიმართ;
- `sticky` — გარკვეულ წერტილამდე ჩვეულებრივ მოძრაობს, შემდეგ ფიქსირდება.

### 9. რა განსხვავებაა `display: none`-სა და `visibility: hidden`-ს შორის?

`display: none` ელემენტს გვერდის განლაგებიდანაც აქრობს და მის ადგილს სხვა ელემენტი იკავებს. `visibility: hidden` ელემენტს მალავს, მაგრამ მისი ადგილი შენარჩუნებულია.

### 10. რამდენი გზით შეგვიძლია HTML დოკუმენტში CSS-ის დამატება?

სამი გზით:

1. Inline CSS — `style` ატრიბუტით;
2. Internal CSS — `<style>` ტეგში;
3. External CSS — ცალკე `.css` ფაილის `<link>` ტეგით დაკავშირება.

External CSS ყველაზე ხშირად გამოყენებული და რეკომენდებული გზაა.

### 11. რა განსხვავებაა `<link>` და `<a>` ტეგებს შორის?

`<link>` გარე რესურსს, მაგალითად CSS ფაილს, აკავშირებს დოკუმენტთან და ჩვეულებრივ `<head>`-ში იწერება. `<a>` ქმნის მომხმარებლისთვის დასაჭერ ბმულს და იყენებს `href` ატრიბუტს.

### 12. რა უპირატესობები აქვს HTML5-ს წინა ვერსიებთან შედარებით?

HTML5-მა დაამატა:

- სემანტიკური ელემენტები, მაგალითად `<header>`, `<main>` და `<article>`;
- `<audio>` და `<video>` ელემენტები;
- ფორმის ახალი input type-ები;
- `<canvas>`;
- უფრო მარტივი doctype — `<!doctype html>`.

### 13. რომელი ტეგებით შეგვიძლია აუდიოსა და ვიდეოს დამატება?

`<audio>` და `<video>` ტეგებით.

```html
<audio src="audio.mp3" controls></audio>
<video src="video.mp4" controls></video>
```

`controls` ამატებს ჩართვის, შეჩერებისა და ხმის მართვის ღილაკებს.

### 14. დაასახელეთ რამდენიმე inline და block ელემენტი.

- Inline: `<span>`, `<a>`, `<strong>`, `<em>`, `<img>`.
- Block: `<div>`, `<p>`, `<h1>`, `<section>`, `<article>`, `<header>`, `<main>`.

Block ელემენტი ჩვეულებრივ ახალ ხაზზე იწყება და ხელმისაწვდომ სიგანეს იკავებს. Inline ელემენტი მხოლოდ შინაარსისთვის საჭირო ადგილს იკავებს.

### 15. რას ნიშნავს სემანტიკური HTML ელემენტი?

სემანტიკური ელემენტის სახელი აღწერს მის დანიშნულებას როგორც დეველოპერისთვის, ისე ბრაუზერისა და დამხმარე ტექნოლოგიებისთვის. მაგალითებია `<nav>`, `<main>`, `<article>` და `<footer>`. `<div>` არ არის სემანტიკური, რადგან მისი სახელი შინაარსის მნიშვნელობას არ აღწერს.

### 16. `<input>` ელემენტის რომელი `type`-ები იცით?

ხშირად გამოყენებული ტიპებია: `text`, `email`, `password`, `number`, `tel`, `url`, `date`, `time`, `checkbox`, `radio`, `file`, `color`, `range`, `search`, `submit`, `reset`, `button` და `hidden`.

### 17. რა დანიშნულება აქვს `<label>` ელემენტს და როგორ ვაკავშირებთ მას `<input>`-თან?

`<label>` აღწერს input-ის დანიშნულებას და აუმჯობესებს ხელმისაწვდომობას. `label`-ის `for` მნიშვნელობა უნდა ემთხვეოდეს input-ის `id`-ს.

```html
<label for="email">Email:</label>
<input type="email" id="email" name="email" />
```

label-ზე დაჭერისას შესაბამისი input აქტიურდება.

## CSS

### 18. რა არის CSS Box Model?

ბრაუზერი თითოეულ HTML ელემენტს მართკუთხა ყუთად აღიქვამს. Box Model შედგება ოთხი ნაწილისგან:

1. `content` — შინაარსი;
2. `padding` — სივრცე შინაარსსა და border-ს შორის;
3. `border` — ელემენტის საზღვარი;
4. `margin` — გარე სივრცე ელემენტის გარშემო.

### 19. CSS-ის რომელი ტიპის სელექტორები იცით?

```css
p {}                 /* element selector */
.card {}             /* class selector */
#header {}           /* id selector */
* {}                 /* universal selector */
input[type="email"] {} /* attribute selector */
.card p {}           /* descendant selector */
.card > p {}         /* child selector */
button:hover {}      /* pseudo-class */
p::first-letter {}   /* pseudo-element */
```

### 20. როგორ შეგვიძლია ერთდროულად გავსტილოთ `h1` და `h2` ელემენტები?

სელექტორები მძიმით უნდა დავაჯგუფოთ:

```css
h1,
h2 {
  color: navy;
}
```

### 21. რომელი CSS property აკონტროლებს ფონური სურათის გამეორებას?

`background-repeat`:

```css
.hero {
  background-image: url("hero.jpg");
  background-repeat: no-repeat;
}
```

### 22. რა განსხვავებაა `margin`-სა და `padding`-ს შორის?

`padding` ქმნის შიდა სივრცეს content-სა და border-ს შორის. `margin` ქმნის გარე სივრცეს ელემენტსა და მის მეზობელ ელემენტებს შორის. ელემენტის background padding-ის სივრცეზეც ვრცელდება, margin-ზე კი — არა.

### 23. რისთვის გამოიყენება `alt` ატრიბუტი `<img>` ელემენტში?

`alt` სურათის ტექსტური აღწერაა. მას screen reader კითხულობს და ასევე გამოჩნდება, თუ სურათი ვერ ჩაიტვირთა. დეკორატიულ სურათზე გამოიყენება ცარიელი `alt=""`.

```html
<img src="student.jpg" alt="Student working on a laptop" />
```

### 24. რა განსხვავებაა `<ul>`, `<ol>` და `<dl>` სიებს შორის?

- `<ul>` — დაულაგებელი, ნიშნულებიანი სია;
- `<ol>` — დალაგებული, დანომრილი სია;
- `<dl>` — აღწერითი სია, რომელიც იყენებს `<dt>` და `<dd>` ელემენტებს.

### 25. რა დანიშნულება აქვს `<form>` ელემენტს?

`<form>` აერთიანებს მომხმარებლის მონაცემების შესატან კონტროლებს და მონაცემებს გადასამუშავებლად აგზავნის. `action` განსაზღვრავს მისამართს, ხოლო `method` — გაგზავნის HTTP მეთოდს.

```html
<form action="/register" method="post">
  <input type="text" name="username" />
  <button type="submit">Register</button>
</form>
```

### 26. რა არის `vw` და `vh`?

- `1vw` არის viewport-ის სიგანის 1%;
- `1vh` არის viewport-ის სიმაღლის 1%.

მაგალითად, `width: 50vw` viewport-ის სიგანის ნახევარია, ხოლო `min-height: 100vh` — viewport-ის სრული სიმაღლე.

### 27. რომელი pseudo-class-ები და pseudo-element-ები იცით?

Pseudo-class აღწერს ელემენტის მდგომარეობას: `:hover`, `:focus`, `:active`, `:checked`, `:disabled`, `:first-child`, `:last-child`, `:nth-child()`.

Pseudo-element ელემენტის კონკრეტულ ნაწილს ან ვირტუალურ ნაწილს არჩევს: `::before`, `::after`, `::first-letter`, `::first-line`, `::placeholder`, `::selection`.

### 28. რა განსხვავებაა `box-sizing: border-box`-სა და `box-sizing: content-box`-ს შორის?

`content-box`-ის დროს მითითებული `width` მოიცავს მხოლოდ content-ს; padding და border მას ემატება. `border-box`-ის დროს მითითებულ სიგანეში content, padding და border უკვე შედის.

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

### 29. რა განსხვავებაა `px`, `%`, `em` და `rem` ერთეულებს შორის?

- `px` — ფიქსირებული CSS ერთეული;
- `%` — მნიშვნელობა ჩვეულებრივ მშობლის შესაბამის ზომაზეა დამოკიდებული;
- `em` — font-size-ისთვის მშობლის ზომაზე, სხვა property-ებისთვის კი მიმდინარე ელემენტის font-size-ზეა დამოკიდებული;
- `rem` — root ელემენტის (`html`) `font-size`-ზეა დამოკიდებული.

თუ root-ის `font-size` არის `16px`, მაშინ `2rem` უდრის `32px`-ს.

### 30. რა არის CSS specificity და რომელ სელექტორს აქვს უფრო მაღალი პრიორიტეტი?

Specificity არის წესი, რომლითაც ბრაუზერი არჩევს, რომელი CSS declaration გამოიყენოს კონკურენტულ წესებს შორის. გამარტივებული პრიორიტეტია:

`inline style` → `id` → `class`/attribute/pseudo-class → element/pseudo-element.

თუ specificity ერთნაირია, ქვემოთ დაწერილი წესი იმარჯვებს. `!important` ჩვეულებრივ კასკადის პრიორიტეტს ცვლის და ფრთხილად უნდა გამოვიყენოთ.

### 31. როგორ მუშაობს `position: relative` და `position: absolute`?

`relative` ელემენტს ჩვეულებრივ ნაკადში ტოვებს და მისი საწყისი ადგილიდან გადაადგილების საშუალებას იძლევა. იგი ასევე reference point ხდება მის შიგნით არსებული absolute ელემენტისთვის.

`absolute` ელემენტს ჩვეულებრივი ნაკადიდან იღებს და უახლოესი ისეთი ancestor-ის მიმართ პოზიციონირებს, რომლის `position` არ არის `static`. ასეთი ancestor-ის არარსებობისას იგი საწყისი containing block-ის მიმართ პოზიციონირდება.

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

### 32. რას აკეთებს `overflow: hidden`?

ელემენტის საზღვრებს გარეთ გასულ შინაარსს ჭრის და მალავს. ის ხშირად გამოიყენება მომრგვალებული კუთხეებიდან გადასული სურათის მოსაჭრელად, თუმცა შეიძლება საჭირო შინაარსიც დამალოს.

### 33. Flexbox-ის რომელი property-ები იცით?

Flex container-ის property-ებია: `display: flex`, `flex-direction`, `justify-content`, `align-items`, `align-content`, `flex-wrap`, `gap`.

Flex item-ის property-ებია: `flex-grow`, `flex-shrink`, `flex-basis`, `flex`, `align-self` და `order`.

### 34. რა განსხვავებაა `justify-content`-სა და `align-items`-ს შორის?

`justify-content` ელემენტებს main axis-ზე ანაწილებს, ხოლო `align-items` — cross axis-ზე. `flex-direction: row`-ის დროს main axis ჰორიზონტალურია, `column`-ის დროს კი ვერტიკალური.

### 35. რას აკეთებს `flex-direction` property?

განსაზღვრავს flex container-ის main axis-სა და ელემენტების განლაგების მიმართულებას. მნიშვნელობებია `row`, `row-reverse`, `column` და `column-reverse`.

### 36. რა განსხვავებაა `row` და `column` მიმართულებებს შორის?

`row` ელემენტებს ძირითად ღერძზე მარცხნიდან მარჯვნივ ალაგებს, ხოლო `column` — ზემოდან ქვემოთ. მიმართულების შეცვლასთან ერთად იცვლება `justify-content`-ისა და `align-items`-ის მოქმედების ღერძებიც.

### 37. რას აკეთებს `flex-wrap: wrap`?

თუ ელემენტები ერთ ხაზზე აღარ ეტევა, `wrap` მათ ახალ ხაზზე გადასვლის უფლებას აძლევს. ნაგულისხმევი მნიშვნელობაა `nowrap`.

### 38. რისთვის გამოიყენება `gap` property?

`gap` flex ან grid ელემენტებს შორის თანაბარ დაშორებას ქმნის. ის კონტეინერის გარე კიდეებთან სივრცეს არ ამატებს.

```css
.cards {
  display: flex;
  gap: 24px;
}
```

### 39. რა განსხვავებაა `width`-სა და `max-width`-ს შორის?

`width` ადგენს სასურველ სიგანეს. `max-width` ადგენს მაქსიმალურ ზღვარს, რომელსაც ელემენტი ვერ გადააჭარბებს. რესპონსიული ელემენტისთვის ხშირად გამოიყენება:

```css
.card {
  width: 100%;
  max-width: 700px;
}
```

### 40. რისთვის გამოიყენება `min-height`?

`min-height` ადგენს ელემენტის მინიმალურ სიმაღლეს, მაგრამ შინაარსის გაზრდისას ელემენტს გაფართოების უფლებას აძლევს. ამიტომ `min-height: 100vh` ხშირად უფრო მოქნილია, ვიდრე `height: 100vh`.

## Responsive Design

### 41. რა არის responsive web design?

Responsive web design არის მიდგომა, რომლის დროსაც გვერდის განლაგება და ზომები სხვადასხვა ეკრანსა და მოწყობილობას ერგება. ამისთვის გამოიყენება მოქნილი ზომები, Flexbox/Grid, რესპონსიული სურათები და media query-ები.

### 42. რა არის media query და როგორ იწერება?

Media query CSS წესებს მხოლოდ კონკრეტული პირობის შესრულებისას ააქტიურებს.

```css
@media (min-width: 768px) {
  .cards {
    display: flex;
  }
}
```

ეს სტილი `768px` და უფრო ფართო viewport-ზე იმუშავებს.

### 43. რა განსხვავებაა `min-width` და `max-width` media query-ებს შორის?

- `min-width: 768px` მუშაობს `768px`-დან ზემოთ;
- `max-width: 768px` მუშაობს `768px`-ზე და ქვემოთ.

`min-width` ხშირად mobile-first მიდგომაში გამოიყენება, `max-width` კი — desktop-first მიდგომაში.

### 44. რას ნიშნავს mobile-first მიდგომა?

თავდაპირველად იწერება პატარა ეკრანის ძირითადი სტილები, შემდეგ კი `min-width` media query-ებით ემატება უფრო დიდი ეკრანის განლაგება.

```css
.menu {
  display: block;
}

@media (min-width: 768px) {
  .menu {
    display: flex;
  }
}
```

### 45. რატომ არის საჭირო `<meta name="viewport">`?

ის მობილურ ბრაუზერს ეუბნება, რომ გვერდის სიგანე მოწყობილობის ეკრანის სიგანეს გაუტოლოს და საწყისი zoom იყოს `1`.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

მის გარეშე რესპონსიული გვერდი მობილურზე შეიძლება დაპატარავებული გამოჩნდეს.

## Additional HTML & CSS Questions

### 46. რა განსხვავებაა `display: block`, `inline` და `inline-block` მნიშვნელობებს შორის?

- `block` — ახალ ხაზზე იწყება და ჩვეულებრივ ხელმისაწვდომ სიგანეს იკავებს;
- `inline` — იმავე ხაზზე რჩება; `width` და `height` ჩვეულებრივ არ მოქმედებს;
- `inline-block` — იმავე ხაზზე რჩება, მაგრამ შეგვიძლია `width` და `height` მივუთითოთ.

### 47. როგორ შეიძლება ელემენტის ჰორიზონტალურად და ვერტიკალურად გაცენტრება Flexbox-ით?

```css
.container {
  min-height: 100vh;
  display: flex;
  justify-content: center;
  align-items: center;
}
```

`justify-content` main axis-ზე, `align-items` კი cross axis-ზე აცენტრებს.

### 48. რა განსხვავებაა `:hover`, `:focus` და `:active` pseudo-class-ებს შორის?

- `:hover` — კურსორი ელემენტის ზემოთაა;
- `:focus` — ელემენტი კლავიატურით ან დაჭერით ფოკუსირებულია;
- `:active` — ელემენტი ამ მომენტში აქტიურდება, მაგალითად ღილაკზე დაჭერისას.

მნიშვნელოვანი ფუნქცია მხოლოდ `:hover`-ზე არ უნდა იყოს დამოკიდებული, რადგან touch მოწყობილობას hover შეიძლება არ ჰქონდეს.

### 49. რას აკეთებს `::before` და `::after` pseudo-element-ები?

ისინი ელემენტის შიგნით, მისი შინაარსის წინ ან შემდეგ, ვირტუალურ ნაწილს ქმნიან. ხშირად დეკორაციისთვის გამოიყენება და ჩვეულებრივ `content` property სჭირდება.

```css
.title::after {
  content: "";
  display: block;
  width: 40px;
  height: 3px;
  background-color: blue;
}
```

### 50. რა დანიშნულება აქვს `z-index` property-ს?

`z-index` განსაზღვრავს გადაფარული ელემენტების stacking order-ს: უფრო მაღალი მნიშვნელობის ელემენტი ჩვეულებრივ წინ ჩანს. შედეგზე stacking context-ებიც მოქმედებს.

### 51. რომელ შემთხვევებში მუშაობს `z-index`?

`z-index` მუშაობს პოზიციონირებულ ელემენტებზე, რომელთა `position` არის `relative`, `absolute`, `fixed` ან `sticky`. ის ასევე მოქმედებს flex და grid item-ებზე. სხვადასხვა stacking context-ში მყოფი ელემენტების შედარება მხოლოდ რიცხვებით ყოველთვის ვერ ხდება.

### 52. რა განსხვავებაა `position: fixed`-სა და `position: sticky`-ს შორის?

`fixed` ელემენტი ჩვეულებრივი ნაკადიდან გამოდის და viewport-ის მიმართ ერთ ადგილზე რჩება. `sticky` თავიდან ჩვეულებრივ ნაკადშია, შემდეგ კი მითითებულ ზღვარზე, მაგალითად `top: 0`-ზე, თავისი scroll container-ის ფარგლებში ეკრობა.

### 53. როგორ დავამატოთ ფონური სურათი CSS-ის გამოყენებით?

```css
.hero {
  background-image: url("images/hero.jpg");
  background-position: center;
  background-size: cover;
  background-repeat: no-repeat;
}
```

CSS ფაილში relative URL ჩვეულებრივ CSS ფაილის მდებარეობის მიმართ ითვლება.

### 54. რას აკეთებს `background-size: cover`?

სურათს პროპორციების შენარჩუნებით ადიდებს ან აპატარავებს ისე, რომ კონტეინერი მთლიანად დაფაროს. ამის გამო სურათის ნაწილი შეიძლება მოიჭრას.

### 55. რა განსხვავებაა `border`-სა და `outline`-ს შორის?

`border` Box Model-ის ნაწილია და ელემენტის ზომაზე შეიძლება იმოქმედოს. `outline` border-ის გარეთ იხატება, ჩვეულებრივ ადგილს არ იკავებს და ხშირად focus-ის საჩვენებლად გამოიყენება. კლავიატურის მომხმარებლისთვის focus outline უმიზეზოდ არ უნდა წავშალოთ.

### 56. რისთვის გამოიყენება `border-radius`?

ელემენტის კუთხეების მოსამრგვალებლად. `border-radius: 50%` თანაბარი სიგანისა და სიმაღლის ელემენტს წრედ აქცევს.

### 57. რას აკეთებს `box-shadow`?

ელემენტს ერთ ან რამდენიმე ჩრდილს ამატებს.

```css
.card {
  box-shadow: 8px 8px 0 black;
}
```

მნიშვნელობები აქ არის: ჰორიზონტალური გადაადგილება, ვერტიკალური გადაადგილება, blur radius და ფერი. `0` ნიშნავს, რომ ჩრდილი არ დაიბლარება.

### 58. რა არის CSS inheritance?

Inheritance ნიშნავს ზოგიერთი CSS property-ის მნიშვნელობის მშობლიდან შვილ ელემენტზე ავტომატურად გადასვლას. მაგალითად, `color` და `font-family` ხშირად მემკვიდრეობით გადადის, ხოლო `margin`, `padding` და `border` — ჩვეულებრივ არა.

### 59. რას ნიშნავს `!important` და რატომ არ არის რეკომენდებული მისი ხშირი გამოყენება?

`!important` declaration-ს ჩვეულებრივ წესებზე მაღალ პრიორიტეტს აძლევს. ხშირი გამოყენება ართულებს სტილების გადაწერას, debugging-სა და კოდის მოვლას. უმჯობესია სწორად ვმართოთ specificity, კასკადი და სელექტორების სტრუქტურა.

### 60. რა განსხვავებაა `opacity: 0`-სა და `display: none`-ს შორის?

`opacity: 0` ელემენტს გამჭვირვალეს ხდის, მაგრამ ის ადგილს ინარჩუნებს და შეიძლება კვლავ მიიღოს pointer events ან focus. `display: none` ელემენტს layout-იდან იღებს და ჩვეულებრივ accessibility tree-დანაც მალავს.

### 61. რა არის BEM სახელდების მიდგომა?

BEM ნიშნავს `Block`, `Element`, `Modifier`-ს. ის CSS კლასების გასაგებად და ორგანიზებულად დასახელებაში გვეხმარება.

```html
<article class="card card--featured">
  <h2 class="card__title">Title</h2>
</article>
```

- `card` — Block;
- `card__title` — Element;
- `card--featured` — Modifier.

### 62. როგორ დავწეროთ კომენტარი HTML-სა და CSS-ში?

```html
<!-- HTML comment -->
```

```css
/* CSS comment */
```

### 63. რისთვის გამოიყენება `<head>` და `<body>` ელემენტები?

`<head>` შეიცავს დოკუმენტის metadata-სა და დაკავშირებულ რესურსებს: `title`, `meta`, CSS-ის `link` და სხვა. `<body>` შეიცავს გვერდის მომხმარებლისთვის ხილულ ძირითად შინაარსს.

### 64. რა განსხვავებაა `<section>`, `<article>` და `<div>` ელემენტებს შორის?

- `<section>` — თემატურად დაკავშირებული შინაარსის განყოფილება, რომელსაც ხშირად სათაური აქვს;
- `<article>` — დამოუკიდებლად გასაგები ან გასავრცელებელი შინაარსი, მაგალითად პოსტი ან სტატია;
- `<div>` — არასემანტიკური კონტეინერი, რომელსაც ვიყენებთ მაშინ, როცა უფრო შესაბამისი სემანტიკური ელემენტი არ არსებობს.

### 65. რატომ არის მნიშვნელოვანი გვერდზე გამართული სათაურების იერარქიის გამოყენება?

სათაურები შინაარსის სტრუქტურას ქმნის და navigation-ს screen reader-ის მომხმარებლებისთვის ამარტივებს. გვერდის მთავარი სათაური ჩვეულებრივ `<h1>`-ია, შემდეგ კი დონეები ლოგიკურად გამოიყენება. HTML სტანდარტი რამდენიმე `<h1>`-ს ტექნიკურად არ კრძალავს, მაგრამ პრაქტიკაში ერთი მკაფიო მთავარი `<h1>` ხშირად ყველაზე გასაგები არჩევანია.

### 66. რა განსხვავებაა GET და POST მეთოდებს შორის HTML ფორმაში?

- `GET` მონაცემებს URL-ის query string-ში აგზავნის; გამოიყენება ძებნისა და მონაცემის მოთხოვნის მსგავსი მოქმედებებისთვის;
- `POST` მონაცემებს request body-ში აგზავნის; გამოიყენება მონაცემის შექმნის ან სერვერზე ცვლილების მოთხოვნისთვის.

POST თავისთავად დაშიფვრას არ ნიშნავს — მონაცემთა უსაფრთხო გადაცემისთვის საჭიროა HTTPS.

### 67. რას აკეთებს `required` ატრიბუტი?

`required` ბრაუზერის ჩაშენებულ validation-ს ეუბნება, რომ ფორმის გაგზავნამდე ველი შევსებული ან არჩეული უნდა იყოს.

```html
<input type="email" name="email" required />
```

სერვერზე validation მაინც აუცილებელია, რადგან client-side validation-ის გვერდის ავლა შესაძლებელია.

### 68. რა დანიშნულება აქვს `placeholder` ატრიბუტს?

`placeholder` ცარიელ input-ში დროებით მინიშნებას აჩვენებს. ის `<label>`-ს არ ცვლის, რადგან ტექსტის შეყვანისას ქრება და accessibility-ისთვის საკმარისი აღწერა არ არის.

### 69. როგორ გავხსნათ ბმული ახალ ჩანართში და უსაფრთხოებისთვის კიდევ რომელი ატრიბუტი გამოვიყენოთ?

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Visit website
</a>
```

`target="_blank"` ბმულს ახალ ჩანართში ხსნის. `noopener` ახალ გვერდს საწყის გვერდზე `window.opener`-ით წვდომას უზღუდავს, ხოლო `noreferrer` referrer ინფორმაციას არ გადასცემს.

### 70. რა არის favicon და როგორ ვამატებთ მას HTML დოკუმენტში?

Favicon არის პატარა ხატულა, რომელიც ბრაუზერის ჩანართში გვერდის სათაურთან ჩანს.

```html
<link rel="icon" href="images/favicon.png" type="image/png" />
```
