# JavaScript --- საშინაო დავალება

## Functions, Loops, Arrays & Objects

ეს დავალებები განკუთვნილია გავლილი მასალის გასამყარებლად.

### წესები

-   გამოიყენე `for` ან `while` loop საჭიროების მიხედვით.
-   შეგიძლია გამოიყენო `if / else` და functions.
-   **არ გამოიყენო:** `map()`, `filter()`, `reduce()`, `some()`,
    `find()`, `sort()`, `reverse()`, `Set`.

------------------------------------------------------------------------

## 1. კენტი რიცხვების რაოდენობა

შექმენი ფუნქცია, რომელიც მიიღებს რიცხვების მასივს და დააბრუნებს რამდენი
კენტი რიცხვია მასში.

``` js
countOdd([2, 5, 7, 8, 10, 13]); // 3
```

## 2. დადებითი რიცხვების ჯამი

მასივიდან შეკრიბე მხოლოდ დადებითი რიცხვები.

``` js
sumPositive([-5, 4, 8, -2, 3]); // 15
```

## 3. ყველაზე დიდი რიცხვი

იპოვე მასივში ყველაზე დიდი რიცხვი. არ გამოიყენო `Math.max()`.

``` js
findLargest([4, 12, 7, 3, 19, 8]); // 19
```

## 4. კონკრეტული რიცხვის რაოდენობა

ფუნქციას გადაეცემა მასივი და რიცხვი. დააბრუნე რამდენჯერ გვხვდება ეს
რიცხვი.

``` js
countNumber([2, 5, 2, 7, 2, 9], 2); // 3
```

## 5. 5-ის ჯერადები

დაბეჭდე `1`-დან `n`-მდე ყველა რიცხვი, რომელიც იყოფა 5-ზე.

``` js
multiplesOfFive(22);
// 5
// 10
// 15
// 20
```

## 6. მასივის ელემენტები უკუღმა

დაბეჭდე მასივის ელემენტები ბოლოდან დასაწყისისკენ. არ გამოიყენო
`reverse()`.

``` js
printBackwards(["a", "b", "c", "d"]);
// d
// c
// b
// a
```

## 7. ხმოვნების რაოდენობა

დათვალე რამდენი ხმოვანია მოცემულ ინგლისურ სიტყვაში. ხმოვნებია `a`, `e`,
`i`, `o`, `u`.

``` js
countVowels("javascript"); // 3
```

## 8. მასივში ნულების რაოდენობა

დათვალე რამდენი `0` არის მასივში.

``` js
countZeros([0, 4, 0, 7, 8, 0]); // 3
```

## 9. რიცხვები ორ ჯგუფად

ლუწი რიცხვები ჩაამატე ერთ მასივში, კენტები --- მეორეში.

``` js
separateNumbers([1, 2, 3, 4, 5, 6]);
// Even: [2, 4, 6]
// Odd: [1, 3, 5]
```

## 10. სიტყვის ბოლო სიმბოლო

დააბრუნე string-ის ბოლო სიმბოლო `.length` და index-ის გამოყენებით.

``` js
getLastCharacter("javascript"); // "t"
```

## 11. ციფრების ჯამი

`while` loop-ის გამოყენებით გამოთვალე რიცხვის ციფრების ჯამი.

``` js
sumDigits(572); // 14
```

## 12. რამდენი ლუწი ციფრია რიცხვში

დათვალე რამდენი ლუწი ციფრია მოცემულ დადებით რიცხვში. გამოიყენე `while`.

``` js
countEvenDigits(48271); // 3
```

## 13. ყველაზე გრძელი სიტყვის სიგრძე

დააბრუნე მასივში ყველაზე გრძელი სიტყვის სიგრძე.

``` js
longestWordLength(["apple", "banana", "kiwi", "watermelon"]); // 10
```

## 14. პირველი საერთო ელემენტი

იპოვე პირველი ელემენტი, რომელიც ორივე მასივში გვხვდება. გამოიყენე nested
loop.

``` js
findCommon([1, 4, 7, 9], [3, 7, 10]); // 7
findCommon([1, 2], [5, 6]); // "No common element"
```

## 15. გამრავლების ტაბულა

დაბეჭდე მოცემული რიცხვის გამრავლების ტაბულა `1`-დან `10`-მდე.

``` js
multiplicationTable(5);
// 5 x 1 = 5
// 5 x 2 = 10
// ...
// 5 x 10 = 50
```

## 16. კვადრატის Pattern

Nested loop-ის გამოყენებით დაბეჭდე:

``` text
****
****
****
****
```

## 17. სტუდენტების ქულების ჯამი

``` js
const students = [
  { name: "Nino", score: 70 },
  { name: "Giorgi", score: 85 },
  { name: "Ana", score: 90 },
  { name: "Luka", score: 60 },
];

sumScores(students); // 305
```

## 18. ჩაბარებული სტუდენტები

დაბეჭდე იმ სტუდენტების სახელები, რომელთა ქულაც `70` ან მეტია. არ
გამოიყენო `filter()`.

``` text
Nino
Giorgi
Ana
```

## 19. ყველაზე მაღალი ქულის მქონე სტუდენტი

იპოვე სტუდენტი, რომელსაც ყველაზე მაღალი `score` აქვს და დააბრუნე მისი
სახელი.

``` js
bestStudent(students); // "Ana"
```

არ გამოიყენო `Math.max()` ან `sort()`.

## 20. სტუდენტის არსებობის შემოწმება

თუ სტუდენტი არსებობს, დააბრუნე `true`, სხვა შემთხვევაში `false`.

``` js
studentExists(students, "Giorgi"); // true
studentExists(students, "Saba"); // false
```

არ გამოიყენო `find()` ან `some()`.
