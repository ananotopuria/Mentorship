# JavaScript — პრაქტიკული დავალებები

**თემები:** DOM, OOP და ასინქრონული JavaScript.

დავალებები შეასრულე თანმიმდევრობით. თითოეულ ეტაპზე შეინახე ფაილი, გაუშვი კოდი და შეამოწმე შედეგი. გამოიყენე ჩვეულებრივი JavaScript, HTML და CSS; დამატებითი ბიბლიოთეკები საჭირო არ არის. ამ ფაილში ამოხსნები არ არის.

## სამუშაო გარემო

VS Code-ში შექმენი საქაღალდე `js-practice` და მასში ფაილები:

- `index.html` — გვერდის სტრუქტურა;
- `dom.js` — DOM დავალებები;
- `oop.js` — კლასებისა და ობიექტების დავალებები;
- `async.js` — ასინქრონული დავალებები;
- `students.json` — ბოლო დავალებისთვის საჭირო მონაცემები.

HTML-ში ერთ ჯერზე ჩართე მხოლოდ შესაბამისი JS ფაილი. DOM ნაწილისთვის გამოიყენე `<script src="dom.js" defer></script>`, შემდეგ შეცვალე `oop.js`-ით ან `async.js`-ით. შედეგებისთვის გახსენი ბრაუზერის DevTools → Console. DOM კოდი გაუშვი ბრაუზერში, რადგან Node.js-ში `document` არ არსებობს.

`fetch`-ის დავალებისთვის გვერდი გაუშვი ლოკალური HTTP სერვერით, მაგალითად VS Code-ის Live Server-ით. Python-ის არსებობისას შეგიძლია ტერმინალში გაუშვა `python3 -m http.server 5500` და გახსნა `http://localhost:5500`. ფაილზე ორმაგი დაწკაპუნებით მიღებული `file://` მისამართი ამ დავალებისთვის არ გამოიყენო.

## ნაწილი 1 — DOM

ქვემოთ მოცემული საწყისი HTML ჩასვი `index.html`-ში. დავალებები 1–6 ერთმანეთს აგრძელებს და ერთ `dom.js` ფაილში სრულდება. უკვე მონიშნული ელემენტის ცვლადი ხელახლა არ გამოაცხადო.

```html
<!DOCTYPE html>
<html lang="ka">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>JavaScript პრაქტიკა</title>
    <style>

  </head>
  <body>
    <h1 id="title">ჩემი პირველი DOM პრაქტიკა</h1>

    <button id="change-title" type="button">სათაურის შეცვლა</button>
    <button id="toggle-style" type="button">სტილის შეცვლა</button>

      <label for="name-input">შენი სახელი</label>
      <input id="name-input" type="text" />
      <button id="greet-button" type="button">მომესალმე</button>
      <p id="greeting" role="status"></p>
    </section>

    <section>

      <p id="load-status" role="status"></p>
      <ul id="student-list"></ul>
    </section>
  </body>
</html>
```

### დავალება 1 — ელემენტების მონიშვნა

1. `getElementById`-ით მონიშნე სათაური და შეინახე ცვლადში.
2. `querySelector`-ით მონიშნე აღწერის აბზაცი.
3. Console-ში დაბეჭდე ორივე ელემენტი.
4. `querySelectorAll`-ით მონიშნე ყველა ღილაკი და დაბეჭდე მათი რაოდენობა.
5. `for...of` ციკლით დაბეჭდე თითოეული ღილაკის ტექსტი.
6. სცადე არარსებული `.missing` კლასის მონიშვნა და Console-ში დააკვირდი შედეგს.

**შემოწმება:** საწყის HTML-ში 9 ღილაკია. არარსებული ელემენტის ძიება აბრუნებს `null`-ს.

### დავალება 2 — ტექსტისა და კლასის შეცვლა

1. გვერდის გახსნისას აღწერა შეცვალე ტექსტით „JavaScript-ით გვერდის მართვა შემიძლია!“.
2. „სათაურის შეცვლა“ ღილაკზე დაჭერისას სათაური გახდეს „DOM მუშაობს!“.
3. „სტილის შეცვლა“ ღილაკზე დაჭერისას სათაურს ჩაერთოს ან გამოერთოს `highlight` კლასი.

**შემოწმება:** სათაური click-მდე თავდაპირველია. სტილის ღილაკზე ზედიზედ ორჯერ დაჭერა თავდაპირველ სტილს აბრუნებს.

### დავალება 3 — მისალმება

1. წაიკითხე `name-input`-ში შეყვანილი სახელი ღილაკზე დაჭერისას.
2. თავიდან და ბოლოდან მოაშორე გამოტოვებები.
3. სახელი თუ ცარიელია, `greeting`-ში გამოჩნდეს „გთხოვ, შეიყვანე სახელი.“.
4. სხვა შემთხვევაში გამოჩნდეს „გამარჯობა, [სახელი]!“.
5. წარმატებული მისალმების შემდეგ input გაასუფთავე.

**შემოწმება:** `  ლიკა  ` → `გამარჯობა, ლიკა!`; მხოლოდ გამოტოვებები → ცარიელი სახელის შეტყობინება.

**მინიშნება:** input-ის მიმდინარე მნიშვნელობა იკითხება `value`-ით; ტექსტის გვერდზე გამოსატანად გამოიყენე `textContent`.

### დავალება 4 — მრიცხველი

1. შექმენი რიცხვითი ცვლადი საწყისი მნიშვნელობით `0`.
2. `+1` ღილაკმა მნიშვნელობა გაზარდოს და გვერდზე განაახლოს.
3. `−1` ღილაკმა მნიშვნელობა შეამციროს, მაგრამ უარყოფითი რიცხვი არ დაუშვას.
4. „განულება“ ღილაკმა მნიშვნელობა დააბრუნოს `0`-ზე.

**შემოწმება:** სამჯერ გაზრდა → `3`; ერთხელ შემცირება → `2`; განულება → `0`; ნულზე შემცირება → ისევ `0`.

**დამატებითი დავალება:** ნულზე შემცირების ღილაკი გათიშე, დადებით მნიშვნელობაზე კი ჩართე.

### დავალება 5 — დავალების დამატება სიაში

1. მოუსმინე ფორმის `submit` მოვლენას და შეაჩერე სტანდარტული გაგზავნა.
2. წაიკითხე და გაწმინდე შეყვანილი ტექსტი.
3. ცარიელი ტექსტისთვის გამოიტანე შეტყობინება „შეიყვანე დავალება.“ და არაფერი დაამატო.
4. შექმენი `li` ელემენტი და ჩასვი შეყვანილი ტექსტი.
5. ახალი ელემენტი დაამატე `task-list`-ში.
6. input გაასუფთავე და მასზე ფოკუსი დააბრუნე.
7. წარმატებისას გამოიტანე შეტყობინება „დავალება დაემატა.“.

**შემოწმება:** დამატება მუშაობს ღილაკითაც და Enter-ითაც; გვერდი არ ახლდება; სამი გაგზავნის შემდეგ სიაში სამი დავალებაა.

### დავალება 6 — შესრულება და წაშლა

გააგრძელე დავალება 5:

1. თითოეული `li`-ის შიგნით ტექსტი მოათავსე `span`-ში.
2. დაამატე ღილაკები „შესრულებულია“ და „წაშლა“.
3. შესრულების ღილაკმა მხოლოდ ამ დავალების ტექსტზე ჩართოს ან გამორთოს `completed` კლასი.
4. წაშლის ღილაკმა მხოლოდ შესაბამისი `li` წაშალოს.
5. „ყველას წაშლა“ ღილაკმა მთელი სია გაასუფთაოს.

**შემოწმება:** ერთის შესრულება მეორეზე არ მოქმედებს; ერთის წაშლა სხვა დავალებებს ტოვებს; ყველა ელემენტის წაშლის შემდეგ ახალი დავალების დამატება ისევ მუშაობს.

**დამატებითი დავალება:** სიასთან აჩვენე დავალებების რაოდენობა და განაახლე დამატების, წაშლისა და სრული გასუფთავებისას. გვერდის განახლების შემდეგ მონაცემების შენარჩუნება ამ დავალებაში მოთხოვნილი არ არის.

## ნაწილი 2 — OOP

HTML-ში ჩართე `oop.js`. დავალებები ამ ფაილში დაწერე. თითოეული კლასისთვის შექმენი ინსტანციები და Console-ში შეამოწმე შედეგები.

### დავალება 7 — ობიექტი მეთოდებით

შექმენი `student` ობიექტი:

- `name`: „ლიკა“;
- `score`: `70`;
- `introduce()` მეთოდი აბრუნებს ტექსტს „მე ვარ ლიკა“;
- `addPoints(points)` მეთოდი მიმდინარე ქულას უმატებს გადაცემულ რაოდენობას.

მეთოდებში გამოიყენე `this`, რათა სახელის ან ქულის ცვლილებისას სწორ მონაცემებზე იმუშაონ.

**შემოწმება:** `student.introduce()` → `მე ვარ ლიკა`; `student.addPoints(10)`-ის შემდეგ `student.score` → `80`.

### დავალება 8 — Student კლასი

1. შექმენი `Student` კლასი, რომლის კონსტრუქტორი იღებს `name`-ს და `score`-ს.
2. დაამატე `introduce()` და `addPoints(points)` მეთოდები წინა დავალების მსგავსად.
3. დაამატე `isPassed()` მეთოდი: ქულა თუ მინიმუმ `60` არის, აბრუნებს `true`-ს, სხვა შემთხვევაში — `false`-ს.
4. შექმენი ორი სტუდენტი: ლიკა — 70 ქულით და ნიკა — 50 ქულით.
5. მხოლოდ ნიკას დაუმატე 15 ქულა.

**შემოწმება:** თავიდან ლიკას `isPassed()` → `true`, ნიკას → `false`; დამატების შემდეგ ნიკას ქულა → `65`, ლიკასი ისევ → `70`.

### დავალება 9 — Product კლასი

შექმენი `Product` კლასი შემდეგი შესაძლებლობებით:

1. კონსტრუქტორი იღებს `name`-ს და `price`-ს.
2. `getInfo()` აბრუნებს ტექსტს „[სახელი]: [ფასი] ლარი“.
3. `getDiscountedPrice(percent)` აბრუნებს ფასდაკლებულ ფასს და საწყის `price`-ს არ ცვლის.
4. ფასდაკლება უნდა იყოს რიცხვი `0`-დან `100`-მდე; სხვა მნიშვნელობისას გამოიწვიე შეცდომა.
5. კონსტრუქტორში არ დაუშვა უარყოფითი ან არარიცხვითი ფასი.

**შემოწმება:** პროდუქტი „წიგნი“, ფასი `40`: 25%-იანი ფასდაკლებით შედეგი → `30`, საწყისი ფასი ისევ → `40`; 0% → `40`; 100% → `0`.

შეცდომის შემთხვევები შეამოწმე `try...catch`-ით: ფასდაკლება `-10`, `120` ან `"20"`.

### დავალება 10 — კერძო ბალანსი

შექმენი `BankAccount` კლასი:

- საჯარო თვისება `owner`;
- კერძო ველი `#balance`, საწყისი მნიშვნელობით `0`;
- `getBalance()` აბრუნებს მიმდინარე ბალანსს;
- `deposit(amount)` ბალანსს ზრდის;
- `withdraw(amount)` ბალანსს ამცირებს.

თანხა უნდა იყოს დადებითი, სასრული რიცხვი. არასწორი თანხისთვის გამოიწვიე შეცდომა. ბალანსზე მეტის გამოტანისას გამოიწვიე შეცდომა „არასაკმარისი თანხა“. შეცდომის შემთხვევაში ბალანსი არ უნდა შეიცვალოს.

**შემოწმება:** შეტანა `100`, გამოტანა `30` → ბალანსი `70`; შემდეგ გამოტანა `100` → შეცდომა და ბალანსი ისევ `70`.

**მინიშნება:** არასწორი გამოძახებები მოათავსე `try...catch`-ში. კერძო ველს კლასის გარედან პირდაპირ ნუ მიმართავ.

### დავალება 11 — მემკვიდრეობა

1. შექმენი `Person` კლასი `name` თვისებით და `introduce()` მეთოდით, რომელიც აბრუნებს „მე ვარ [სახელი]“.
2. შექმენი `Teacher` კლასი, რომელიც მემკვიდრეობას იღებს `Person`-ისგან.
3. მის კონსტრუქტორს გადაეცეს `name` და `subject`; მშობლის კონსტრუქტორი გამოიძახე `super`-ით.
4. დაამატე `teach()` მეთოდი: აბრუნებს „[სახელი] ასწავლის [საგანი]-ს“.
5. შექმენი მასწავლებელი და გამოიძახე ორივე მეთოდი.

**შემოწმება:** „ანანო“, „JavaScript“ → `მე ვარ ანანო` და `ანანო ასწავლის JavaScript-ს`.

### დავალება 12 — ერთი მეთოდი, სხვადასხვა შედეგი

1. შექმენი `Animal` კლასი `speak()` მეთოდით, რომელიც აბრუნებს „ცხოველის ხმა“.
2. შექმენი შვილ კლასები `Dog` და `Cat`.
3. ორივეში ხელახლა აღწერე `speak()`: ძაღლი აბრუნებს „ჰამ ჰამ“, კატა — „მიაუ“.
4. შექმენი მასივი ორი ინსტანციით და ციკლში თითოეულზე გამოიძახე `speak()`.

**შემოწმება:** Console-ში თანმიმდევრობით გამოჩნდება `ჰამ ჰამ` და `მიაუ`.

**დაფიქრდი:** რატომ შეგვიძლია ერთი და იგივე მეთოდის სახელის გამოყენება სხვადასხვა ობიექტზე?

## ნაწილი 3 — ასინქრონული JavaScript

HTML-ში ჩართე `async.js`. დავალებები 13–17 გაუშვი ცალ-ცალკე: წინა მაგალითი დროებით დააკომენტარე, რათა შედეგები ერთმანეთს არ შეერიოს. დავალება 18 საბოლოო გვერდის პრაქტიკაა.

### დავალება 13 — შესრულების თანმიმდევრობა

გაშვებამდე დაწერე შენი ვარაუდი, რა თანმიმდევრობით გამოჩნდება ტექსტები. შემდეგ გაუშვი და შენი პასუხი შეადარე Console-ს.

```js
console.log("დასაწყისი");

setTimeout(function () {
  console.log("ტაიმერი დასრულდა");
}, 1000);

console.log("დასასრული");
```

წერილობით უპასუხე: რატომ არ ელოდება ბოლო `console.log` ტაიმერს? შემდეგ დრო შეცვალე `0`-ით და კვლავ შეამოწმე შენი ვარაუდი.

### დავალება 14 — Promise და ტაიმერი

გაშვებამდე ივარაუდე შედეგების რიგი:

```js
console.log("A");

setTimeout(function () {
  console.log("B");
}, 0);

Promise.resolve().then(function () {
  console.log("C");
});

console.log("D");
```

გაშვების შემდეგ ახსენი შენი სიტყვებით: რომელი ნაწილი შესრულდა სინქრონულად? რომელი callback დაიგეგმა მიკროტასკად? რატომ არ ნიშნავს ტაიმერის `0` დაუყოვნებლივ შესრულებას?

### დავალება 15 — საკუთარი Promise

შექმენი `getCourse(shouldFail = false)` ფუნქცია:

1. ფუნქციამ დააბრუნოს Promise.
2. დაახლოებით ერთი წამის შემდეგ, თუ `shouldFail` არის `false`, Promise წარმატებით დასრულდეს ობიექტით `{ name: "JavaScript", lessons: 20 }`.
3. თუ `shouldFail` არის `true`, Promise უარყოფილი იყოს `Error` ობიექტით და ტექსტით „კურსი ვერ ჩაიტვირთა“.
4. გამოიყენე `.then()` წარმატებული შედეგის დასაბეჭდად.
5. გამოიყენე `.catch()` შეცდომის შეტყობინების დასაბეჭდად.
6. გამოიყენე `.finally()` ტექსტისთვის „მოთხოვნა დასრულდა“.

**შემოწმება:** ცალ-ცალკე სცადე `getCourse()` და `getCourse(true)`; ორივე შემთხვევაში დასრულების ტექსტი უნდა დაიბეჭდოს.

### დავალება 16 — async/await

წინა დავალების `getCourse` ფუნქცია დატოვე, ხოლო `.then/.catch/.finally` გამოძახება ჩაანაცვლე:

1. შექმენი `async` ფუნქცია `showCourse()`.
2. დასაწყისში დაბეჭდე „იტვირთება...“.
3. `await`-ით მიიღე კურსი და დაბეჭდე მისი სახელი და გაკვეთილების რაოდენობა.
4. შეცდომა დაამუშავე `try...catch`-ით.
5. `finally`-ში დაბეჭდე „ჩატვირთვა დასრულდა“.
6. გამოიძახე `showCourse()` და მის შემდეგ, ფუნქციის გარეთ, დაბეჭდე „სხვა კოდი გრძელდება“.

**შემოწმება:** გარე ტექსტი უნდა გამოჩნდეს კურსის მიღებამდე. შეამოწმე წარმატებისა და შეცდომის გზები.

**დაფიქრდი:** `await` რას აყოვნებს — მთელ პროგრამას თუ კონკრეტული async ფუნქციის გაგრძელებას?

### დავალება 17 — Promise.all

შექმენი ორი ფუნქცია:

- `getStudents()` — დაახლოებით 1 წამში წარმატებით აბრუნებს `["ლიკა", "ნიკა"]`-ს;
- `getSubjects()` — დაახლოებით 1.5 წამში წარმატებით აბრუნებს `["JavaScript", "HTML"]`-ს.

ორივე ოპერაცია დაიწყე და `Promise.all`-ით მიიღე მათი შედეგები. გამოიყენე `async/await` და შეცდომის დამუშავება.

**შემოწმება:** შედეგი შეიცავს ორ მასივს, გადაცემული Promise-ების რიგის მიხედვით. საერთო დრო დაახლოებით 1.5 წამი ან მეტია და არა ორივე დაყოვნების ჯამი.

**დამატებითი დავალება:** ერთმა ფუნქციამ უარყოფილი Promise დააბრუნოს და შეამოწმე, სად მოხვდება შესრულება.

### დავალება 18 — სტუდენტების ჩატვირთვა გვერდზე

`students.json`-ში ჩასვი:

```json
[
  { "id": 1, "name": "ლიკა", "score": 90 },
  { "id": 2, "name": "ნიკა", "score": 85 },
  { "id": 3, "name": "მარი", "score": 95 }
]
```

გამოიყენე საწყისი HTML-ის `load-students`, `load-status` და `student-list` ელემენტები. `async.js`-ში დატოვე მხოლოდ ამ დავალებისთვის საჭირო კოდი.

1. ღილაკზე დაჭერისას დაიწყე `fetch("./students.json")` მოთხოვნა.
2. ჩატვირთვისას სტატუსში გამოჩნდეს „იტვირთება...“ და ღილაკი გაითიშოს.
3. ძველი სია გაასუფთავე, რათა ხელახლა ჩატვირთვამ დუბლირება არ გამოიწვიოს.
4. შეამოწმე `response.ok`; წარუმატებელი HTTP სტატუსისთვის გამოიწვიე შეცდომა.
5. `response.json()`-ით მიიღე მონაცემები.
6. თითოეული სტუდენტისთვის შექმენი `li`: „[სახელი] — [ქულა] ქულა“.
7. წარმატებისას სტატუსი გახდეს „სტუდენტები ჩაიტვირთა.“.
8. ცარიელი მასივისთვის გამოჩნდეს „სტუდენტები არ მოიძებნა.“.
9. შეცდომისას გამოჩნდეს „მონაცემები ვერ ჩაიტვირთა.“.
10. მოთხოვნის დასრულების შემდეგ ღილაკი ისევ ჩაირთოს — წარმატებისასაც და შეცდომისასაც.

**საკუთარი შემოწმება:**

- წარმატებისას სიაში სამი სტუდენტია;
- მეორედ ჩატვირთვის შემდეგ ისევ სამი სტუდენტია;
- Network ჩანართში ჩანს JSON-ის მოთხოვნა;
- `./missing.json` მისამართით ჩანს შეცდომის შეტყობინება და ღილაკი ისევ აქტიურია;
- JSON-ში `[]`-ის ჩასმით ჩანს ცარიელი სიის შეტყობინება.

შემოწმების შემდეგ დააბრუნე სწორი მისამართი და საწყისი JSON. Loading-ის უკეთ სანახავად შეგიძლია DevTools-ის Network ჩანართში დროებით შეანელო ქსელი.

**მინიშნება:** `fetch` 404/500 პასუხზე ავტომატურად არ უარყოფს Promise-ს. სტატუსი თავად შეამოწმე. ღილაკის ხელახლა ჩართვისთვის გამოგადგება `finally`.

## დამატებითი საერთო პროექტი — სურვილისამებრ

გააერთიანე სამივე თემა სტუდენტების პატარა გვერდში:

1. შექმენი `Student` კლასი `name`, `score` და `isPassed()` მეთოდით.
2. JSON-დან მიღებული თითოეული სტუდენტისგან შექმენი `Student` ინსტანცია.
3. გვერდზე გამოიტანე სახელი, ქულა და სტატუსი: „ჩააბარა“ ან „ვერ ჩააბარა“; ჩაბარების ზღვარია `60`.
4. დაამატე ღილაკი „მხოლოდ ჩაბარებულები“, რომელიც უკვე მიღებულ მონაცემებს გაფილტრავს და სიას ხელახლა გამოსახავს.
5. დაამატე ღილაკი „ყველა“, რომელიც სრულ სიას დააბრუნებს ახალი მოთხოვნის გაგზავნის გარეშე.

თუ ჯერ მასივის `filter` არ გამოგიყენებია, შესაბამისი სტუდენტები ციკლით შეარჩიე. შემოწმებისთვის ერთ სტუდენტს დროებით დაუწერე `50` ქულა.

## ჩაბარებამდე

- ფაილები შენახულია და HTML-ში საჭირო სკრიპტია ჩართული.
- თითოეული ნაწილის შემოწმებისას Console-ში მოულოდნელი შეცდომა არ ჩანს.
- DOM-ში მომხმარებლის ტექსტი გამოგაქვს `textContent`-ით.
- OOP დავალებებში შექმნილი გაქვს ინსტანციები და შედეგები შემოწმებული გაქვს.
- ასინქრონულ დავალებებში შემოწმებულია წარმატებაც და შეცდომაც.
- კოდს ახლავს მოკლე კომენტარები იქ, სადაც შენი გადაწყვეტილების ახსნა საჭიროა.

**ჩასაბარებელი:** პროექტის საქაღალდე ან მისი ZIP ფაილი. თან დაურთე დავალებების 13, 14 და 16-ის კითხვებზე მოკლე პასუხები. ყველა ნაწილი რომ აჩვენო, მიუთითე: DOM → `dom.js`, OOP → `oop.js`, Async → `async.js`.
